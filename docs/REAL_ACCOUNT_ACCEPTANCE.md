# 0.7.2 候选版真实账号验收

本文是验收说明，不是“验收已通过”的记录。开发、自动化构建和合成测试继续在云端进行；下面的登录网页步骤由所有者在独立浏览器配置中执行，不要求把账号凭据交给云端。

## 安装与识别

从准确 HEAD 的成功 GitHub Actions 运行取得 candidate artifact。外层 ZIP 内含 Edge/Chrome 候选包和 SHA256SUMS。再解压 Edge 候选包，把含 manifest.json 的目录加载到独立 Edge 配置。

检查 BUILD_INFO.json 的 source_commit 是否与要验收的 PR 提交一致。不要安装 main 中的上游快照，不要覆盖旧研线或清理其数据。候选版采用单独扩展存储，不能自动继承旧扩展数据。

## 最小真实闭环

使用不含敏感内容的测试对话，包含 PDF、XLSX、CSV、图片和一个助手生成文件。预先记录各文件的字节哈希和三个可验证事实，分别来自对话早期、中间、末尾。

1. 开启已有对话，在研线工作区明确选择该标签页，点击保存。核对消息范围、分支状态、原始文件名、文件大小、哈希与缺失原因。
2. 下载归档 ZIP。解压后核对 manifest、conversation.json、conversation.md 和 assets 文件。至少抽样重算上传文件和生成文件的 SHA-256。恢复后确认来源按消息角色重新判定；重复 key、消息与节点不匹配、未知 manifest 文件和伪造的范围状态均应被拒绝。
3. 关闭并重新打开浏览器，重新打开研线。原档案、真实文件字节和缺失状态应仍存在。随后从 ZIP 恢复一份独立档案，原档案不得被覆盖。
4. 勾选本次需要的原始文件，填写简短目标，生成接续包。核对 handoff_index.md 中的原名、上传名和哈希。同名但不同内容的文件必须区分。
5. 点击打开新窗口，确认它是普通新聊天。历史作为附件，输入框为短提示。观察上传；状态未知时不要当成已完成，使用暂存区下载文件并人工上传。
6. 所有材料核对后，由用户手动发送。让新对话回答早期、中间、末尾的预置事实，读取两个原始附件中的指定值；回答应能对应实际文件内容。

模型答对某个问题不能证明整份历史都进入上下文，也不证明后续长任务永不遗漏。记录测试范围，不使用“全部无缝继承”作为未经测量的结论。

## 文件保存范围专项验收（0.7.2）

两种范围都应保存完整的可见对话正文和分支结构；差异只在文件字节下载范围。

1. 选“保存对话中的所有文件”，准备包含用户上传文件、助手生成文件和替代分支生成文件的测试对话。核对所有可识别引用均有独立状态，成功文件字节与 SHA-256 一致。
2. 选“仅保存最后生成的文件”，在当前分支生成至少两份文件，并在替代分支生成另一份文件；同时保留用户上传附件。预期只下载当前分支最后生成的一份助手文件，其余项目明确标记“按保存范围跳过”，不得发起文件下载请求。
3. 用没有助手生成文件的对话测试。预期完整正文仍保存，提示当前分支没有可识别的生成文件，不得把用户上传文件误选为生成文件。
4. 导出 ZIP 并恢复，核对 `saveScope`、`excluded` 状态和文件字节哈希均保留；官方 ZIP 对照报告应将跳过项标记为 `excluded_by_save_scope`，不计为远端缺失。
5. 选择“仅最后生成的文件”时，实时缓存应禁用；通过扩展界面和后台命令分别验证该组合均被拒绝。来源不明的工具文件若早于最后一份已确认助手文件，后者仍可保存；若来源不明文件晚于或位于同一消息，不能猜测较早文件，所有可能候选均应标记未判定且不发起下载。
6. 只在替代分支存在助手生成文件、当前分支没有生成文件时，不能把替代分支文件当成当前分支最后生成文件；应保存正文并明确提示当前分支没有匹配文件。

若真实 ChatGPT 的文件引用不能可靠区分助手生成与用户上传，或无法映射到活动分支消息，必须将状态标记为 `SAVE_SCOPE_SOURCE_UNRESOLVED`，单独计入未判定，不纳入最后生成文件选择；若它可能晚于当前候选，当前候选也不得自动保存。不能仅凭文件名或时间猜测来源。

## 必测边界

| 场景 | 预期行为 |
| --- | --- |
| 当前可读的上传文件和生成文件 | 保存实际字节并核对哈希；不是只存文件名或临时链接。 |
| 几个月前的真实旧对话 | 记录可读/不可读，不预设固定过期时间；403/404/422 不等同于永久删除。 |
| 缓存开启后新生成文件 | 只在选定对话内缓存；显式停止后不再采集。关闭浏览器/后台重启后暂停，不静默重放。 |
| 原始远端文件已失效 | 已缓存文件仍可用；未缓存文件明确缺失，不能注入空文件。 |
| 12、21 个以上附件 | 索引、历史也计数；可配置批次，首批之外人工补充，不声称自动突破网页上限。 |
| 目标有草稿或已选文件 | 停止自动注入，保留已有内容；不清空或覆盖。 |
| 错误目标：旧聊天、项目、临时聊天、未知 URL | 拒绝自动注入。 |
| 上传控件改变、上传超时或状态不明 | 释放控制权，显示未知；不自动重试或发送。 |
| 浏览器刷新/重复点击 | 不重复创建同一接续窗口、不重复注入已领取的接续。 |
| 删除本地档案 | 先停止采集，只删除本地档案及其接续记录；共享文件仍供其他档案使用；源对话不变。 |
| 官方导出 ZIP | 读取实际格式。准确文件 ID 或唯一文件名可对照；未知映射保留未识别，不挑选成功样本。 |
| 大文件/磁盘空间不足 | 验证浏览器实际容量和中断行为。未运行压力测试前不宣称最大容量。 |

## 证据与隐私

只需记录安装包 SHA、浏览器版本、用例 ID、成功/失败/未知、错误代码和必要的脱敏截图。真实对话 JSON、附件、官方 ZIP、Token、Cookie 和签名 URL 不上传到公开仓库。

当前工程 CI 使用合成材料，不能替代此文中的真人登录步骤。生产发布仍须单独批准。主分支合并、稳定版发布、旧产品删除均不由本验收说明自动授权。
