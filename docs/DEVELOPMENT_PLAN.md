## 产品目标与安全不变量

将指定 ChatGPT 对话的可见内容、分支关系和可取得的附件真实字节保存到本地档案；支持 ZIP 导出/恢复、完整性核验，并将历史与用户选定的原始附件安全带入普通新聊天。

1. 不修改或删除源对话/项目；不自动点击 Send，不静默重试。
2. 不覆盖目标聊天已有草稿或附件；目标必须是空白普通新聊天，不是 Project、Temporary 或旧对话。
3. 只有非零真实字节通过大小与 SHA-256 校验才可标记已保存；未知、缺失、损坏分别呈现。
4. 采集、实时缓存、接续均绑定明确来源对话、标签页、任务和目标文档；页面身份变化即停止。
5. 认证信息、Cookie、签名 URL、真实对话正文和附件不得进入 GitHub、ZIP 元数据或诊断日志。
6. 上传状态只有在网页给出可验证完成状态时才标记确认；未知时交还控制权，不自动重试、不发送。
7. ZIP 恢复必须验证 schema、路径、条目、大小、哈希和完整性；拒绝截断、歧义或越界输入。
8. 任何自动化测试均不得替代真实账号、真实旧资料或真人验收。

## 0.7.2 文件保存范围

本次增量在保存对话主流程增加文件范围选项。两种模式均保存完整可见正文、可访问分支结构和文件引用元数据；选项只控制哪些文件字节会被尝试下载。

- **全部文件（默认）：** 尝试下载所有可访问分支中的用户上传文件、助手生成文件及其他文件引用。来源不明的文件仍会尝试下载，失败时保留实际错误状态。
- **仅最后生成的文件：** 只下载当前活动分支最后一条包含助手生成文件的消息中的最后一份文件。用户上传文件、已确认的其他分支文件标记为 `excluded / OUT_OF_SAVE_SCOPE`。
- 来源不明或无法映射到消息节点的文件标记为 `unavailable / SAVE_SCOPE_SOURCE_UNRESOLVED`，单独计入未判定。若来源不明文件晚于或处于最后一份已确认生成文件的同一消息位置，不能确定真正的最后文件；所有可能的助手生成候选也标记为未判定，不自动挑选较早文件。若来源不明文件早于最后一份已确认生成文件，后者仍可被选择。
- 只有当前活动分支的助手生成文件参与“最后生成”选择。仅在替代分支出现的生成文件不会被误选；如果当前分支没有生成文件，正文仍保存，并明确提示。
- “仅最后生成”与实时缓存互斥，界面禁用实时缓存，服务端也拒绝该组合。
- ZIP 恢复按快照中的消息角色重新推导文件来源；拒绝重复文件 key、附件与消息节点不匹配、未知 manifest 文件、伪造的按范围状态，以及把较早文件伪装成最后生成文件。
- 全部文件模式的 ZIP 不允许出现按范围排除项；单文件模式中的排除与未判定状态写入档案、manifest、恢复结果和接续清单。官方 ZIP 对照分别呈现 `excluded_by_save_scope` 与未保存项，不混为一谈。

自动化验收覆盖：全部文件模式尝试下载替代分支和来源不明文件；单文件模式只下载目标文件；来源不明文件在前/在后时的选择差异；仅替代分支有生成文件时不误选；实时缓存互斥；ZIP 导出/恢复；来源角色伪造、重复 key、消息节点错配、伪造排除状态和未知 manifest key 的拒绝。
