# 0.7.1 UX 简化验收记录

## 设计目标

以 Uber 乘客端的任务型交互作为参照：用户打开页面后能识别当前任务、唯一主操作和下一步；不要求先理解功能模块。

## 界面决策

- 首页：选择对话并保存。我的档案为次级入口。
- 保存完成：保存按钮退出主位，显示保存结果和“继续这段对话”。
- 档案页：选择档案后突出“继续这段对话”；归档下载、官方 ZIP 对照、附件选择、历史阅读和删除均为次级/折叠操作。
- 接续页：填写可选目标，突出“准备新对话”；生成后突出“打开新聊天”。文件清单、批次设置、提示词和上传核对默认折叠。
- 高级设置：媒体权限、实时缓存、存储持久化不占据主流程。
- 保留明确的保存、下载、上传、发送状态，不以界面简化为由弱化数据完整性提示或安全约束。
